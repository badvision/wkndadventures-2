# cards-ticker

Custom **cards** block. Purpose: Thin full-width strip of activity words scrolling horizontally in an infinite loop.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item, one text cell (Cards no-images model): e.g. Climbing, Kayaking, Cycling, Desert, Photography, Hiking, Winter, Surfing, Expedition, Wild Swimming.
