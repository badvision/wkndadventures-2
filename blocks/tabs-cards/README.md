# tabs-cards

Custom **tabs** block. Purpose: Activity tab switcher whose panels each render a 3-column grid of bordered article cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab, two cells: [tab label] [repeating card groups: image, tag paragraph, H3 linked to the article, description paragraph].

No variations.
